# File Cleaner
Removes duplicates from the target directories (or CWD if none were provided).
It does not recurse into sub-directories.

## Why Zig?
Zig supports [cross-compilation as a first-class use case](https://ziglang.org/learn/overview/#cross-compiling-is-a-first-class-use-case) + It's a popular compiled language I liked the sound of.
